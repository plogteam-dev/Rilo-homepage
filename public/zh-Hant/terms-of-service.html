第一章 總則

第1條（目的）

本條款之目的，在於規範使用RILO（以下稱「公司」）所提供之服務（以下稱「服務」）時，公司與使用者之權利、義務及責任事項，以及其他必要事項。

第2條（定義）

  1. 「服務」係指公司所提供之行動應用程式及相關一切服務。
  2. 「使用者」係指依本條款使用服務之人。
  3. 「貼文」係指使用者於服務內撰寫、登錄、分享之一切形式內容（文字、圖片、影片等）。
  4. 「個人資料」係指得以識別特定個人之資訊，依相關法令之定義。

第3條（條款之效力及變更）

  1. 本條款對所有註冊並欲使用本服務之使用者發生效力。
  2. 本條款於服務應用程式內線上公告後發生效力，如有合理事由，公司得於不違反相關法令之範圍內變更本條款。
  3. 公司得於必要時修訂條款，修訂後之條款將透過服務內之公告事項事先公告。
  4. 同意本條款，即表示同意定期造訪服務網站以確認條款之變更事項。
  5. 公司變更條款時，將以服務內公告事項或其他適當方式（服務內公告事項、通知等）事先告知變更事項。
  6. 使用者不同意變更後之條款時，得停止使用服務並退出會員。
  7. 於變更後條款之施行日後仍繼續使用服務者，視為同意條款之變更。

第二章 使用契約之締結

第4條（使用契約之成立）

  1. 使用契約於使用者同意本條款並完成註冊程序時成立。
  2. 本服務條款之同意程序，由公司揭示於服務使用申請畫面，並於使用者知悉本條款及同意程序且完成申請時成立。

第5條（服務使用申請）

  1. 欲註冊並使用本服務者，應填寫並提交公司所要求之各項資訊。
  2. 所有使用者均須連結本人實際持有之Google、KakaoTalk或Apple帳號申請使用服務，未正確填寫者不得主張任何權利。如有冒用第三人名義或以不正當方法使用者，得依相關法令受處罰。

第6條（服務之提供及變更）

  1. 公司提供下列服務。
    • 使用者得填寫及管理紀錄之服務
    • 使用者得與其他使用者分享紀錄並互動之服務
  2. 公司得依營運上、技術上之需要變更或終止服務內容，變更服務時，得透過網站事先公告變更之服務內容及提供日期，並變更服務提供予使用者。
  3. 公司得運用於服務營運中所蒐集之使用者服務使用行為等資訊改善服務，並導入新功能及服務。

第7條（服務使用之限制及中斷）

  1. 公司於下列各款情形，得限制或中斷使用者之服務使用。
    • 使用他人名義申請者
    • 申請使用服務時虛偽填寫內容者
    • 欲以不正當用途使用本服務者
    • 欲以營利為目的使用本服務者
    • 經判斷可能對公司之服務提供造成損害者
    • 註冊申請人曾經喪失使用資格者（但喪失資格後已逾1年，且經公司同意重新註冊者，不在此限）
    • 其他違反所規定之各項事項而申請者
  2. 公司因天災、系統故障、緊急安全措施、戰爭、暴動、傳染病、國家緊急狀態、電信事業者之服務障礙等不可避免之事由，得未經事先公告中斷服務之提供。但於可正常提供服務時，將立即公告並盡最大努力進行復原。
  3. 公司對於因上述事由所生之服務中斷、資料遺失、無法使用等損害，不負任何法律責任。

第三章 契約當事人之義務

第8條（公司之權利與義務）

  1. 除有特殊情事外，公司應持續且穩定地向使用者提供服務。
  2. 公司建置保護個人資料之安全系統，並公告及遵守個人資料處理方針。
  3. 公司認為使用者提出之意見或不滿為正當時，應採取適當措施。
  4. 公司因緊急系統檢修、國家緊急狀態、設備故障、服務使用者暴增等原因難以提供正常服務時，將事先或事後向使用者公告事由及期間等。

第9條（使用者之權利與義務）

  1. 使用者應遵守本條款及公司之營運政策，不得妨礙公司業務或損害公司名譽。
  2. 使用者不得於服務內從事違法行為或侵害他人權利。
  3. 使用者應妥善管理自己的帳號及個人資料。
  4. 使用者於申請註冊或變更資訊時，應依據事實填寫所有事項，若使用虛偽或他人之資訊登錄，不得主張作為「使用者」之一切權利。
  5. 使用者未經公司事先同意，不得利用服務從事營業活動，公司對該營業活動不負責任。又使用者因上述營業活動致公司受有損害時，應負損害賠償責任。
  6. 使用者有下列各款行為時，公司得對使用者採取限制服務使用等適當之限制措施。
    • 於申請註冊或變更資訊時登錄虛偽內容之行為
    • 盜用其他使用者之ID、密碼等個人資料之行為
    • 與他人交易使用者ID之行為
    • 冒充公司之營運人員、員工或相關人員之行為
    • 未經公司授予特別權利而變更公司之應用程式、入侵公司之伺服器，或擅自變更網站或所揭示資訊之一部或全部之行為
    • 危害或故意妨礙公司所提供服務之行為
    • 未經公司事先同意，將透過本服務取得之資訊複製用於服務使用以外之目的，或用於出版及廣播等，或提供予第三人之行為
    • 以傳送、張貼、電子郵件或其他方式向他人散布違反公共秩序及善良風俗之低俗、淫穢內容之資訊、文句、圖形、聲音、影片之行為
    • 以傳送、張貼、電子郵件或其他方式向他人散布具侮辱性或涉及個人身分，可能侵害他人名譽或隱私之內容之行為
    • 騷擾或威脅其他使用者，或於多數使用者間煽動紛爭，或持續對特定使用者造成痛苦或不便之行為
    • 未經公司許可蒐集或儲存其他使用者個人資料之行為
    • 經客觀判斷與犯罪相關之行為
    • 違反包含本條款在內之其他公司所定各項規定或使用條件之行為
    • 其他違反相關法令之行為

第10條（帳號管理及個人資料之保護）

  1. 為使用服務，使用者應提供正確之資訊，因提供虛偽資訊所生之不利益，不受保護。
  2. 公司保護使用者之個人資料，並依相關法令實施適當之保護措施。
  3. 使用者所登錄之資訊與事實不符時，公司得限制其服務使用。
  4. 帳號之管理責任在於使用者，不得轉讓或與他人共用。
  5. 個人資料之蒐集、利用、提供等相關事項，依另行訂定之隱私權政策。

第四章 服務之提供及使用

第11條（貼文之著作權及服務使用）

  1. 服務所包含之一切內容（文字、圖片、軟體等）之著作權及其他權利，歸屬於公司或正當權利人。
  2. 使用者未經公司明示同意，不得擅自重製、散布、修改內容。
  3. 使用者不得將透過服務取得之資訊加以加工、販售等，將服務所刊載之資料用於營利目的或使第三人使用。
  4. 貼文之著作權受著作權法保護，公司所創作之著作物之著作權及其他智慧財產權歸屬於公司。
  5. 於服務內張貼之貼文之著作權歸屬於張貼之使用者。如該貼文侵害第三人之智慧財產權，一切責任由張貼貼文之使用者負擔，公司因此受他人請求損害賠償等時，使用者應努力使公司免責，公司未能免責時，應賠償公司之一切損害。
  6. 公司未經張貼者同意，不得將貼文作商業利用，如將貼文用於外部廣告、付費行銷或與第三人合作等商業目的時，應另行取得同意。
  7. 公司判斷使用者於服務內張貼或登錄之內容、貼文該當第9條第6項各款情形時，得予以刪除或拒絕登錄。
  8. 使用者授予公司使用權，使公司得於國內外基於下列各款目的使用使用者於服務內公開張貼之貼文。
    • 為於服務（包含進駐第三人經營之網站或媒體之一定區域內提供服務之情形）內使用貼文，以轉換貼文大小或簡化等方式加以修改。
    • 於公司或關係企業所經營之本服務及串接服務中重製、傳輸、展示貼文。但使用者以電子郵件通知管理者反對貼文之重製、傳輸、展示時，不在此限。
    • 為宣傳公司服務之目的，使媒體、通訊社等報導、播放貼文之內容。於此過程中，貼文之內容得於不變更其本質內容之範圍內，經摘要為部分文句或省略等編輯。又公司將使合作夥伴無法存取作者之個人資料，作者請求刪除個人資料及停止張貼時，將立即採取刪除貼文、停止張貼等措施。

第12條（貼文之管理及責任）

  1. 使用者對其於服務中張貼之內容負責。
  2. 公司對於下列貼文，得不經事先通知予以刪除或限制存取。
    • 對其他使用者或第三人造成嚴重侮辱或損害名譽之內容
    • 散布或連結違反公共秩序及善良風俗之內容
    • 助長非法複製或駭客行為之內容
    • 以營利為目的之廣告
    • 經客觀認定與犯罪相關之內容
    • 侵害其他使用者或第三人之著作權等其他權利之內容
    • 違反公司所規定之貼文原則，或不符合看板性質者
    • 其他經判斷違反相關法令者

第13條（資訊之提供）

  1. 公司於營運服務時，得將各種資訊刊載於服務畫面，或依需要以各種方式向使用者提供資訊。
  2. 公司得基於改善服務等目的，於使用者同意下要求額外之個人資料。

第14條（位置資訊之利用）

  1. 公司為提供有用之服務，得蒐集、利用位置資訊（GPS）。
  2. 本服務係自蒐集使用者終端裝置位置資訊之位置資訊事業者接收位置資訊而提供之免費服務，位置資訊之利用及保護相關事項，依另行訂定之位置服務使用條款。
  3. 使用者得全部或部分撤回對服務相關之個人位置資訊利用、提供之同意，並得要求暫時停止。
  4. 使用者全部或部分撤回同意時，公司將立即銷毀撤回部分之個人位置資訊及位置資訊利用、提供事實之確認資料。

第15條（廣告刊登）

  1. 公司向使用者提供之服務，其投資基礎之一部分來自刊登廣告之收益。公司得就服務營運於網站、服務畫面、應用程式等刊登廣告，使用者同意於使用服務時所顯示之廣告刊登。
  2. 使用者利用服務上所刊登之廣告，或參與廣告主透過服務進行之促銷活動等方式進行通訊或交易，完全屬於使用者與廣告主之間的問題，對於因此所生之損失及損害，公司不負任何責任。

第五章 使用之撤回及其他

第16條（契約之變更及終止）

  1. 使用者欲終止使用契約時，應由使用者本人透過服務內之退出會員程序辦理。
  2. 契約終止後，除依法令及隱私權政策保存使用者資訊之情形外，原則上刪除使用者資訊及使用者撰寫之貼文等一切資料。
  3. 但使用者於第三人之貼文新增留言等貼文，或使用者撰寫之貼文經第三人收藏或以其他分享功能張貼，以及其他可能直接或間接影響其他使用者使用服務之情形，該貼文可能不會自動刪除。如不希望如此，請事先設為不公開或刪除。

第17條（責任之限制）

  1. 公司於法令允許之限度內，對於本條款未明示之任何具體事項不作任何約定或保證。例如，公司對於服務所含之內容、服務之特定功能、服務之可用性不作任何約定或保證，僅依現況提供服務。
  2. 公司對於因天災、網路障礙、外部攻擊等不可抗力事由所致之服務障礙，不負責任。
  3. 公司因電信事業者中止電信服務或未正常提供而發生損害時，免除其責任。
  4. 對於使用者使用本服務所生之問題，除公司有故意或重大過失外，不負責任。
  5. 公司對於因使用者之電腦錯誤所生之損害，或因使用者不實填寫個人資訊及電子郵件地址所生之損害，不負責任。
  6. 公司對於使用者於使用服務時因其他使用者所受之精神損害，不負賠償責任。
  7. 公司對於使用者於服務上刊登之各種資訊、資料、事實之可信度、正確性等內容，不負責任。
  8. 公司對於使用者相互間及使用者與第三人間以服務為媒介所生之爭議，無介入之義務，亦不負賠償因此所生損害之責任。

第18條（爭議解決及管轄法院）

  1. 公司優先處理使用者所提出之不滿事項及意見。但難以迅速處理時，將通知使用者其事由及大致之處理時程。
  2. 公司與使用者之間發生爭議時，將誠實協商，努力圓滿解決。
  3. 本條款未明示之事項，依大韓民國《電信事業法》等相關法令及商業慣例。
  4. 因使用服務所生之爭議提起訴訟時，以管轄公司總公司所在地之法院為管轄法院。
